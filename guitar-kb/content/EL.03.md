### Legato: notes without picking
Hammer-ons, pull-offs and slides make lines sing and flow instead of sounding "picked".

### Hammer-on (h)
Pick a note, then **slam** another finger onto a higher fret on the same string without picking. Example in the G box: pick string 4 fret 2 (E), hammer fret 5 (G).

### Pull-off (p)
The reverse: fret two notes, pick the higher, then **pull** the top finger slightly sideways off the string so it plucks the lower note. Example: string 3, fret 4 to fret 2.

### Slide (/ \\)
Pick a note and slide the same finger to the target fret while keeping pressure. Land exactly on the fret. Example: string 3, fret 2 slide up to fret 4. Worship leads use slides constantly into melody notes.

### Practice
- **Trills**: hammer and pull between two frets for 30 seconds, every note equally loud.
- **Phrase**: string 3 fret 2 / 4 (slide), string 2 fret 3 h 5, pull back off 5 to 3, land on string 3 fret 4. Play it in time.

{{tool:metronome:bpm=70,beats=4,sub=2}}

> The hammered and pulled notes should be as loud as the picked ones. If they disappear, the hammer is too soft or the pull-off isn't plucking.

### Goal
Smooth legato phrases at 70 BPM, in time, with even volume.
