### Tune every time you pick up the guitar
Strings drift with temperature, humidity and playing. An out-of-tune guitar makes correct chords sound wrong, so tuning is the first minute of every practice.

### With the tuner
1. Tap **Tuner** at the top of this lesson (or open Tools).
2. Pluck one open string and let it ring. Don't touch other strings.
3. The note name shows which string the app hears. The needle shows how far off it is in **cents** (a cent is 1/100 of a fret).
4. Needle left = flat, turn the peg to **tighten**. Needle right = sharp, **loosen** a little past the note, then come back up.
5. Green means within 3 cents. Do all six, then check them all once more, because tightening one string pulls the neck slightly.

> Always tune **up** to the note. Coming down to it leaves slack in the gear and the string slips flat.

### The 5th-fret method (no tuner)
Once string 6 is right, the others can be tuned to it:

| Fret this | Should match |
|---|---|
| String 6, fret 5 | Open string 5 |
| String 5, fret 5 | Open string 4 |
| String 4, fret 5 | Open string 3 |
| String 3, fret **4** | Open string 2 |
| String 2, fret 5 | Open string 1 |

The G to B pair is the odd one out (fret 4), because B is only four frets above G.

### Goal
All six strings within ±5 cents. You can tap the string names on the tuner to hear each reference note.
