### Play any song from a number chart
On a number chart, the band agrees on a key and everyone translates on the fly. For electric players that's natural: triads and barre shapes **move**, so a number is just a position on the neck relative to the 1.

### The neck map
In any key, find the **1** on string 6 or 5. Then, using barre or triad shapes:
- **4** = same fret, one string higher (root on string 5), or 5 frets up on the same string.
- **5** = 2 frets up, one string higher (root on string 5).
- **6m** = 3 frets down on the same string (E-shape minor), or 4 frets up on the next string (A-shape minor).
- **2m** = 2 frets up on the same string.

Example in G (1 = string 6, fret 3): 4 = C at string 5 fret 3, 5 = D at string 5 fret 5, 6m = Em at string 5 fret 7, 2m = Am at string 6 fret 5.

Practice the shapes until you see "1, 4, 5, 6m" as a box of positions, not as letters.
