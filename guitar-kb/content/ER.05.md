> Notice the shapes differ from the 3-2-1 set. That's the G→B string tuning again (T.01): any shape that crosses from string 3 to string 2 shifts a fret.

### Practice
1. Find G, C, D and Em on strings 4-3-2 within frets 2 to 7.
2. Play 1–5–6m–4 in G using only this string set, moving as little as possible.
3. Combine: verse on 4-3-2, chorus on 3-2-1. The part "lifts" without getting louder.
