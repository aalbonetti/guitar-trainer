### Put it together
**Amazing Grace** uses only G, C, D (and a passing G7), in 3/4. It brings together the waltz strum, chord changes and a capo.

{{song:SONG_amazing_grace}}

### How to play it
1. **Count in**: it starts on beat 3 (a pickup), so count "1, 2," and start singing on 3.
2. Strum the **waltz** pattern, one bar per chord box.
3. The **G7** before the C is just G with the 1st string at fret 1: a little push toward C.
4. Second time through, try the rolling arpeggio from A.10.

{{rhythm:S4_waltz}}

### Change the key
A congregation usually sings it in **A** or **Bb**: capo 2 or 3 with the same G shapes. Try singing it in all three.

### The three-chord hymn set
Many old hymns use only 1, 4 and 5. Once Amazing Grace is solid, try the same chords on other hymns you know.

### Pass it
Strum the waltz pattern through the chords to the click, one bar per chord. Without a capo it's in G; pick capo 2 or 3 if you want the A or Bb version.

{{exercise:EX_amazing_grace_chords}}

### Goal
The whole hymn at tempo, chords changing on time.
